# ⚡ Mahsan Portfolio

A modern, dynamic, and professional portfolio website built with **Next.js 14**, **React 18**, and **TypeScript**. This portfolio features a stunning dark-themed design with smooth micro-interactions, a unique blob mascot, and advanced animations to showcase projects and technical expertise.

## 🚀 Features

- **Modern Design**: Cutting-edge UI with neumorphism-inspired elements and glassmorphism effects.
- **Dynamic Blob Mascot**: Features an animated **Blobster** character that reacts to user interaction.
- **Next.js 14 App Router**: Leverages the latest features of Next.js for optimal performance and developer experience.
- **TypeScript Support**: Type-safe codebase with static typing.
- **Advanced Animations**:
  - **Lenis Smooth Scrolling**: Ultra-smooth page scrolling with inertia.
  - **GSAP**: Advanced animation library for complex micro-interactions.
  - **Framer Motion**: Declarative animations for UI elements.
- **Interactive Elements**:
  - **Magnetic Buttons**: Buttons that follow the cursor.
  - **Cursor Trail**: Custom cursor with trailing effects.
  - **Parallax Backgrounds**: Layered backgrounds that move at different speeds.
- **Portfolio Content**:
  - **Projects Section**: Detailed showcase of technical projects with status indicators (Live, In-Progress, Coming Soon).
  - **Skills Section**: Comprehensive list of technical skills and tools.
  - **Experience**: Professional work history.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Library**: [React 18](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**:
  - [GSAP (GreenSock)](https://greensock.com/)
  - [Framer Motion](https://www.framer.com/motion/)
- **Scrolling**:
  - [Lenis](https://github.com/studio-freight/lenis)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Vercel

## ⚙️ Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AHSANooo/Portfolio.git
   cd mahsanportfolio
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Run the development server**:
   ```bash
   pnpm dev
   ```

## 💻 Running Locally

- **Development**: `pnpm dev`
- **Build**: `pnpm build`
- **Start**: `pnpm start`

## 🚀 Deployment

This project is optimized for deployment on Vercel. You can deploy it by:

1. Importing the repository into Vercel.
2. Setting environment variables (none required for basic setup).
3. Running the build and start commands automatically.

## 🎯 Key Features in Detail

### Blobster Mascot
![Blobster](public/blobster.png)

The portfolio features an interactive 3D-like blob character that reacts to mouse movement, adding a playful and engaging element to the user experience.

### Micro-Interactions
- **Mouse Tracking**: The custom cursor and blob follow the user's mouse.
- **Parallax Effects**: Background elements move independently for a sense of depth.
- **Magnetic Elements**: Buttons and interactive items attract the cursor.

### Performance
- **Code Splitting**: Only loads necessary code for each page.
- **Optimized Assets**: Images and animations are optimized for fast load times.
